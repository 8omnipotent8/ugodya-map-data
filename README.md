# Ugodya Map Data

Публичное хранилище офлайн-карты для приложения «Угодья».

## Текущая карта

- Регион: Крым
- Формат: PMTiles (векторная схема OpenMapTiles)
- Версия: `2026-10-01`
- Дата данных OpenStreetMap: `2026-10-01T20:22:06Z`
- Размер: 160 916 779 байт
- SHA-256: `82e62780130788b0b85bbbe613053ac6ea9d17e797ec41d0bd84cc1f211ebf78`

Приложение получает адрес и контрольную сумму из файла
[`map-catalog.json`](map-catalog.json), скачивает карту, проверяет SHA-256 и
сохраняет её во внутренней памяти телефона для работы без интернета.
